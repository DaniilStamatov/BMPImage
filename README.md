# BMPImage

## Описание проекта

`BMPImage` - это проект на C++, который реализует класс для работы с изображениями в черно-белом формате BMP. Класс позволяет открывать изображения, рисовать линии, сохранять измененные изображения и отображать их в консоли с использованием символов `#` и пробелов.

## Функциональность

- **Открытие изображения**: Класс может загружать изображения в черно-белом формате BMP из указанного пользователем полного пути.
- **Рисование линий**: Пользователь может рисовать линии на изображении, указывая начальные и конечные координаты.
- **Сохранение изображения**: Измененное изображение может быть сохранено в файл.
- **Отображение изображения**: Изображение выводится в консоль, где черные пиксели отображаются символом `#`, а белые - пробелом.

## Структура проекта
- `res/` - папка с исходными изображениями в формате BMP.
- `result/` - папка для сохранения результатов работы программы.
- `main.cpp` - основной файл, который запускает программу.
- `Makefile` - файл для сборки проекта.
